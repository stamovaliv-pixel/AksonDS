# Doxi 3.4.0 — изменения

- Единый Cognitive Core с ограниченным JSON-планированием только многоэтапных аналитических запросов.
- Read-only выбор инструментов ограничен базой знаний и текущими данными DockSlot; мутации остаются в штатных серверных обработчиках.
- Расширенный поиск корпоративной информации с дополнительными терминами и персональным контекстом.
- Многоэтапная аналитика и ограниченный проверочный проход на локальной Qwen.
- Автоматическое восстановление очевидной раскладки/опечаток; оригинальная реплика в истории не изменяется.
- Обработка напоминаний с отдельным текстом и различением пропущенных/прошедших даты и времени.
- Изолированный Brave LLM Context Web Search только для `super_admin`.
- Однофайловая Edge Function для Supabase Dashboard; дополнительных TypeScript модулей нет.
- Обновлённый loopback-only proxy с allow-list только `qwen3.5:9b`, JSON mode, восемью HTTP workers и лимитом 24 принятых запросов.
- Frontend обновлён для команд поиска и ссылок на источники.
