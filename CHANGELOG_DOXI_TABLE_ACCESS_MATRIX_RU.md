# Изменения — Матрица доступа Докси к таблицам

## Добавлено
- Таблица `public.doxi_table_permissions` с RLS и запретом прямого доступа из браузерных ролей.
- Инициализация разрешений для 25 таблиц из текущего списка Supabase.
- Интерфейс матрицы на странице управления Докси: SELECT / INSERT / UPDATE / DELETE, область строк, лимит.
- Серверные API `admin_get_table_permissions` и `admin_update_table_permissions`, доступные только `super_admin`.
- Проверка разрешения на каждом серверном чтении и поддерживаемом изменении.
- Hard-lock для `profiles` (read-only) и `push_subscriptions` (полный запрет).
- Hard-lock внутренних таблиц `doxi_action_drafts` и `doxi_settings` для обычного чтения через чат.
- Учет `max_rows` при контекстном чтении и календарных запросах по `bookings`.
- Чтение содержимого таблиц через матрицу ограничено ролями `admin` и `super_admin`.
- Версионирование CSS/JS страницы управления для сброса кеша браузера.

## Без изменений
- Локальная Ollama, модель Qwen, proxy и Cloudflare Tunnel.
- Логика обычного интерфейса DockSlot, кроме секции управления матрицей.
- Действия с бронированиями продолжают использовать черновики и отдельное подтверждение.
- Чтение профилей не имеет write-пути.
