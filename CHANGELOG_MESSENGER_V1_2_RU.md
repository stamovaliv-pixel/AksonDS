# DockSlot Messenger v1.2 — изменения

1. Пересборка поверх последнего `AksonDS-main (21).zip`; новые функции наложены на актуальные файлы проекта.
2. Прозрачный оранжевый значок с числом непрочитанных на карточках записи страницы дня и рабочего стола администратора.
3. Значок и содержимое доступны только участникам конкретного чата/адресатам сообщения. Персональные сообщения в одной записи изолированы друг от друга.
4. Роль `supplier` полностью исключена из мессенджера.
5. Получатели: личный выбор по `profiles.company_name`; быстрые группы УТЗ (`admin`) и РЦ (`operator`); фильтр по ролям, разрешённым суперадминистратором.
6. В группе можно отправить как общее сообщение всем участникам, так и адресное одному участнику.
7. Счётчик на карточке суммирует непрочитанные сообщения из всех диалогов этой записи.
8. Архив суперадминистратора доступен через Edge Function с проверкой JWT и роли; прямой RPC архивной истории отозван у `authenticated`.
9. Существующие бизнес-модули не переписаны; подключение чата исключено со страницы поставщиков.

## Внедрение
- Выполнить миграцию `supabase/migrations/20261124_dockslot_messenger_v1_2.sql` в тестовом Supabase.
- Задеплоить `supabase/functions/dockslot-chat-admin-history`.
- Протестировать роли `admin`, `operator`, `super_admin`, `supplier`; особенно две личные переписки на одном booking_id.
