# Doxi 3.4 — функциональная карта и границы релиза

| Направление | Реализация в 3.4 | Граница |
|---|---|---|
| Понимание ввода | Раскладка, набор частых опечаток, восстановление в оперативном контексте | Не переписывает историю; неоднозначные фразы может уточнять |
| Планирование | JSON-план сложности и чтения источников | Запускается только на многоэтапных аналитических запросах |
| Инструменты | Справочная база и live data — read-only; операции — прежние серверные handlers | У модели нет прямого SQL/произвольного tool execution |
| Память | Диалог, резюме, персональная память, корпоративные материалы | Семантические подсказки сейчас расширяют ключевой поиск; векторного pgvector-индекса нет |
| Рассуждение | Аналитический brief, план этапов, проверочный проход | Использует ту же локальную 9B; не обещает безошибочность |
| Модель | Qwen 3.5 9B для всех синхронных запросов | Qwen3:14B не маршрутизируется из-за измеренного времени ответа и лимитов Supabase |
| Интернет | Brave LLM Context API, до 6 источников | Только явный публичный запрос, только super_admin, нужен Secret |
| Вложения | CSV/XLS/XLSX локально через текущую Edge Function → Ollama | Ограничения по объёму и выборке сохранены |
| Бронирования | Текущие защищённые сценарии и карточки | Требуется отдельное подтверждение человека |

Этот файл намеренно отделяет реализованное поведение от будущих направлений (настоящий vector RAG, отдельный inference server для тяжёлой модели, автономное многошаговое выполнение произвольных инструментов).
