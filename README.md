# Портал записи поставщиков на РЦ «AKSon Logistics»

Проект готов к загрузке на GitHub Pages. 

## Шаги по запуску:
1. Зарегистрируйтесь на [Supabase](https://supabase.com).
2. Создайте новый проект и выполните SQL-скрипт (представленный ранее) в SQL Editor.
3. Перейдите в настройки Supabase (Project Settings -> API) и скопируйте `URL` и `anon public key`.
4. Откройте файл `js/supabase-client.js` в этом проекте и вставьте туда скопированные ключи.
5. Загрузите все эти файлы в репозиторий на GitHub.
6. Включите GitHub Pages в настройках репозитория (Settings -> Pages -> deploy from 'main' branch -> root).
7. Готово! Ваш портал доступен по ссылке GitHub Pages.
