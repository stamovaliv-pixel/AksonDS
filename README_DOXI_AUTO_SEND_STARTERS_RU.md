# DockSlot — отправка стартовых вопросов Докси по клику

## Что изменено

- Три стартовых вопроса под приветствием Докси теперь сразу отправляются в чат при нажатии.
- Используется существующая общая функция `send()`: вопрос проходит тот же путь, что и обычное сообщение из поля ввода, включая восстановление текущего диалога, индикатор ожидания, вызов Supabase Edge Function и вывод ответа.
- Убрано прежнее поведение, при котором клик только копировал текст вопроса в textarea.
- Добавлена блокировка повторного запуска отправки на время асинхронного восстановления диалога, чтобы быстрый повторный клик не создавал дубли.
- Обновлён cache-buster `ai-ds.js` на всех 14 страницах, подключающих Докси, чтобы браузер загрузил новую версию скрипта.

## Установка

Замените файлы из архива патча в GitHub по тем же путям, сохраняя структуру каталогов, затем опубликуйте проект. Альтернатива — использовать полный обновлённый архив проекта.

После публикации откройте DockSlot и выполните жёсткое обновление страницы (`Ctrl + F5`). SQL, Supabase Edge Function, Proxy, Ollama и Cloudflared менять не требуется.

## Проверки

- `node --check js/ai-ds.js` — успешно.
- Проверено, что обработчик `data-prompt` вызывает `send(prompt)` и больше не записывает текст в textarea.
- Проверено, что все 14 подключений `ai-ds.js` используют новый cache-buster.
- Живой браузерный тест и обращение к рабочей Edge Function не выполнялись.
