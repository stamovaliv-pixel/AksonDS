# Doxi Hotfix 3 — корректная обработка напоминаний

## Для какой версии

Однофайловая версия Edge Function, созданная на основе Doxi 2.0 MultiRole + Attachment Analysis (node-xlsx 0.25.0) + Input Understanding Hotfix 2 Single File. Вариант не требует `input-understanding.ts` и других дополнительных файлов.

## Что исправлено

1. Парсер отличает отсутствующую дату, отсутствующее время, неверную дату/время, время в прошлом и время менее чем через минуту.
2. Если пользователь указал прошедшее время, Докси объясняет, что оно уже прошло по Москве, и предлагает указать более позднее время или завтра. Напоминание задним числом не создаётся.
3. Поддерживает естественные формулировки:
   - `создай напоминание на сегодня в 20:30 с текстом У меня лучший руководитель`
   - `напомни сегодня в 20:30 что у меня лучший руководитель`
   - `напомни завтра в 10:30: проверить реестр`
4. В запись напоминания попадает только сам текст, без слов `с текстом`, `что`, даты и времени.
5. Сохранение по-прежнему выполняется только сервером в `admin_personal_reminders` и только для владельца; подтверждение факта создания — только после успешного ответа БД.
6. Сохранены текущие функции бронирований, памяти, чтения живых данных, анализа CSV/XLS/XLSX и Input Understanding.

## Установка через Supabase Dashboard

1. Откройте Supabase Dashboard → Edge Functions → `doxi-chat` → Code.
2. Скачайте резервную копию функции через кнопку Download.
3. В списке FILES откройте `index.ts`.
4. Откройте этот файл из архива `supabase/functions/doxi-chat/index.ts` в Блокноте.
5. Скопируйте всё содержимое (Ctrl+A, Ctrl+C), замените всё содержимое `index.ts` в редакторе Supabase (Ctrl+A, Ctrl+V).
6. Не создавайте дополнительные файлы. В этом hotfix только один `index.ts`.
7. Нажмите Deploy updates и дождитесь `Successfully updated edge function`.

## Проверка

На момент подготовки исходного сценария 14.11.2026 19:12 МСК, поэтому `сегодня в 19:00` — время в прошлом. Ожидаемое поведение после патча: Докси явно говорит, что время прошло, и не пытается создавать напоминание.

После публикации протестируйте:

- `напомни завтра в 19:00 что у меня лучший руководитель` — должен создаться текст `у меня лучший руководитель` на завтра в 19:00 МСК;
- `создай напоминание на сегодня в 20:30 с текстом У меня лучший руководитель` — если 20:30 ещё впереди, должен создаться текст `У меня лучший руководитель` на сегодня в 20:30 МСК;
- `напомни сегодня в 19:00 что у меня лучший руководитель` после 19:00 — должно объяснить, что время прошло, без записи в БД.

## Проверки, выполненные локально

- TypeScript синтаксически успешно transpile-ится.
- Проверены извлечение текста и расписания для обеих пользовательских формулировок.
- Проверено, что слова внутри `проверить` не обрезаются при удалении служебного слова `про`.
- Проверена дата/время в прошлом: возвращается причина `past`, запись не формируется.
- Реальное развёртывание и запись в Supabase не выполнялись этим пакетом; их подтверждает только пользователь после Deploy updates и end-to-end теста.
