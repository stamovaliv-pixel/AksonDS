# DOXI v1.10.4 — исправление создания и подтверждения записей

Отдельный исправительный релиз для текущей линии Doxi v1.10.4. Патч 2.1 Web Search не включён и не меняется.

## Что исправлено

1. **Продолжение диалога после уточнения поставщика.** Если в исходном запросе указаны дата и час, но не указан поставщик, сервер сохраняет незавершённые параметры в `doxi_action_drafts` со статусом `awaiting_supplier`. Следующее сообщение «Поставщик Аксон» обрабатывается сервером как продолжение этого шага, а не отправляется свободно языковой модели.
2. **Распознавание номера документа.** Поддерживается обычная фраза `номер документа 21312`, а также варианты `номер: 21312`, `документ №21312`, `новый номер 21312`.
3. **Тип поставки из запроса.** «Интернет-магазин» / «Заказ ИМ» преобразуется в ключ `orders_im` и имеет приоритет над типом из исходной записи.
4. **Текстовое «подтверждаю» не создаёт запись.** Если есть действующий черновик, сервер заново отдаёт карточку подтверждения с одноразовым токеном. Если черновика нет, сообщает, что действие не выполнено. Запись может быть создана только вызовом `commit_action` по кнопке.
5. **Проверка фактического результата на клиенте.** Frontend не показывает сообщение об успехе, пока Edge Function не вернёт `ok=true`, совпадающий тип операции и результат SQL; для создания дополнительно требуется `booking_id`.
6. **Проверка рабочего календаря.** Перед подготовкой подтверждения сервер сверяет день недели и исключённые даты с `app_settings`. При недоступной дате карточка не создаётся.
7. **Защита от старых карточек.** При повторной выдаче токена в чате остаётся только самая новая карточка действия.

## Файлы для замены

- `supabase/functions/doxi-chat/index.ts` — заменить исходник Edge Function.
- `js/ai-ds.js` — заменить клиентский скрипт Докси.
- `app/*.html` — заменить 14 страниц из архива: в них обновлена только версия cache-busting для `ai-ds.js`.

CSS, таблицы Supabase, SQL-функции, RLS и права ролей не изменяются. SQL-миграции для этого патча не требуются.

## Публикация

1. Сделайте резервную копию текущего `supabase/functions/doxi-chat/index.ts`, `js/ai-ds.js` и HTML-файлов.
2. Замените перечисленные файлы в репозитории.
3. Опубликуйте Edge Function:

```powershell
supabase functions deploy doxi-chat
```

4. Опубликуйте frontend тем же способом, которым вы обычно публикуете DockSlot через RelaxDev/Vercel.
5. После публикации выполните тестовый сценарий ниже. Не используйте старую карточку из ранее открытой вкладки.

## Тестирование

В конфигурации Supabase, присланной для аудита, доступны дни `1,2,3,4,5` (понедельник–пятница). Поэтому **14 ноября 2026 года — суббота — недоступно для бронирования**. Сервер должен отказать в подготовке на 14.11 и сообщить ближайшую доступную дату по календарю — при неизменных настройках это понедельник 16.11.2026.

Для функционального теста используйте следующий рабочий день и поставщика, у которого есть активная исходная запись, например:

`Создай запись слота на 2026-11-16 в 16:00, тип поставки интернет-магазин, номер документа 21312`

Затем отдельным сообщением:

`Поставщик Аксон`

Ожидаемое поведение:
- сервер продолжает сохранённый сценарий;
- если поставщик найден однозначно и у него есть активная запись, в чате появляется карточка с параметрами и кнопкой «Подтвердить»;
- до нажатия кнопки запись не меняется;
- текст «подтверждаю» только повторно показывает карточку, но не выполняет операцию;
- после нажатия кнопки сервер проверяет правила DockSlot и только при успешном SQL commit сообщает об успехе.

Если у поставщика нет активной записи-образца, Докси должна сообщить об этом и не показывать карточку.

## Безопасность и ограничения

- Доступ к Supabase по-прежнему выполняется сервером через Edge Function.
- Существующие проверки `doxi_commit_booking_action`, RLS и триггеры бронирований не изменяются.
- Поставщик по-прежнему может работать только со своими записями; текущий релиз не расширяет перечень ролей.
- Интернет-поиск Brave не добавляется.
- Серверная проверка даты — предварительная; окончательное решение всё равно остаётся за штатной SQL-функцией и триггерами DockSlot.
