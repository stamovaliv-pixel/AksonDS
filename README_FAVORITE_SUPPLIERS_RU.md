# Избранные поставщики — 20.11.2026

## Что добавлено

- Новая таблица `public.admin_favorite_suppliers`: связь `user_id` + `supplier_profile_id`, уникальная для каждой пары. Один поставщик может быть избранным у нескольких администраторов.
- RLS разрешает читать, добавлять и удалять только собственные избранные профили активным пользователям с ролью `admin` или `super_admin`.
- На странице «Пользователи» у каждого поставщика добавлена компактная звёздочка: пустая — не избранный, золотая — избранный. Состояние хранится в Supabase.
- На страницах «Пользователи», «Календарь администратора», «День администратора» и «Рабочий стол» добавлен компактный переключатель «Показать избранных».
- Включённый фильтр ограничивает записи `bookings` идентификаторами поставщиков из персонального списка текущего пользователя. Пустой список не снимает фильтр и не показывает все записи.
- Докси получает «мои/избранные поставщики» из `admin_favorite_suppliers` по `user_id` текущей сессии. Перечень не включается в системный промпт и не записывается в личную память.
- Запросы Докси о записях избранных поставщиков выводят поставщика, дату, время слота и тип поставки.
- SQL-миграция удаляет из `doxi_user_memory` только старые записи списков поставщиков (`title = 'Мои поставщики'` или JSON-маркер `doxi-my-supplier-v1`). Обычная личная память пользователя не удаляется.

## Порядок публикации

1. Сделать резервную копию БД.
2. Выполнить в Supabase SQL Editor файл `supabase/migrations/20261120_admin_favorite_suppliers.sql`.
3. Опубликовать статические файлы проекта целиком, сохранив структуру `app/`, `css/`, `js/`.
4. Опубликовать Edge Function `doxi-chat` из `supabase/functions/doxi-chat/`.
5. Проверить вход под двумя разными администраторами: избранное первого не должно отображаться у второго.

## Проверки после публикации

- Добавить одного поставщика в избранное у администратора A и убедиться, что у администратора B звезда пустая.
- Добавить того же поставщика у администратора B; оба пользователя должны видеть его как избранного.
- Включить «Показать избранных» на каждой из четырёх страниц; записи должны ограничиваться только личным списком.
- У пользователя с пустым списком при включённом фильтре не должно отображаться ни одной записи.
- В чате Докси проверить: «Покажи избранных поставщиков», «Покажи записи избранных поставщиков» и запрос на конкретную дату.
- Проверить, что старые supplier-list записи удалены, а обычные заметки и предпочтения в личной памяти остались.

## Важное

Фильтр интерфейса и список Докси используют одну таблицу. Избранное не меняет глобальный профиль поставщика и не влияет на видимость записей для других ролей.
