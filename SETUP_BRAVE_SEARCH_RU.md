# Настройка Brave Search для Doxi 3.4

1. Создайте API key в кабинете Brave Search API: https://brave.com/search/api/.
2. В Supabase Dashboard откройте Project Settings → Edge Functions → Secrets и добавьте:
   - Name: `BRAVE_SEARCH_API_KEY`
   - Value: ваш Brave API key.
3. Не помещайте ключ в `js/ai-ds.js`, CSS, HTML, GitHub или сообщения Докси.
4. Откройте DockSlot под ролью `super_admin` и используйте:

```text
/интернет актуальная документация Supabase Edge Functions
```

Ожидается ответ на русском языке и отдельный блок ссылок на HTTPS-источники.

## Что уходит в Brave

Только отдельная публичная поисковая фраза, которую пользователь явно направил через `/интернет` или распознанную команду «найди в интернете ...». Не передаются история чата, память, имя пользователя, роль, страница DockSlot, база бронирований и вложения. Если выбран файл, frontend сначала попросит убрать его.

Сервер блокирует запросы с очевидными email, UUID, телефонами, ИНН, ВзУ и номерами документов. Это эвристический фильтр, он не гарантирует распознавание любых персональных данных, поэтому в поиске должны быть только публичные темы.

Внешние фрагменты считаются недоверенными и не могут управлять Докси или выполнять действия. Результаты поиска не сохраняются в `doxi_messages`. Доступ к действию `web_search` проверяется по реальной роли `super_admin` на сервере.

## Диагностика

- 503 с текстом «поиск не настроен» — отсутствует `BRAVE_SEARCH_API_KEY`.
- 503 «Brave Search отклонил API-ключ» — проверьте ключ в Supabase Secrets.
- 429 — достигнут лимит API или внутренний лимит пользователя (10 запросов/минуту).
- 403 под другими ролями — ожидаемое поведение.

Удаление `BRAVE_SEARCH_API_KEY` отключает веб-поиск, не выключая обычный чат.
