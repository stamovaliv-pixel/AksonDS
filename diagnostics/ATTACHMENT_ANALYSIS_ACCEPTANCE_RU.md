# Приёмочные сценарии — Doxi 2.0.1 Attachment Analysis

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Прикрепить CSV UTF-8 с `;` и отправить «Проанализируй файл» | Докси называет файл CSV, определяет разделитель и анализирует строки |
| 2 | Прикрепить CSV Windows-1251 | Кириллица читается без кракозябр |
| 3 | Прикрепить XLS | Читаются значения и название листа |
| 4 | Прикрепить XLSX с двумя листами | В ответе перечислены оба листа и их содержимое |
| 5 | Прикрепить XLSX с большим числом листов/строк | Указывается, что анализировалась ограниченная часть |
| 6 | Прикрепить файл больше 10 МБ | Понятный отказ, данные не сохранены |
| 7 | Прикрепить файл и отправить пустое сообщение | Используется запрос по умолчанию на анализ вложения |
| 8 | Прикрепить CSV при команде создания записи | Сначала штатная карточка подтверждения; реестр не загружается до подтверждения |
| 9 | Обычный запрос без файла | Работает прежний чат без изменений |
| 10 | Просмотреть историю диалога | Сохраняются текст вопроса и имя файла; содержимое файла отсутствует |

Дополнительно: проверить обычный доступ по ролям — серверный доступ по `allowed_roles` остаётся источником полномочий.
