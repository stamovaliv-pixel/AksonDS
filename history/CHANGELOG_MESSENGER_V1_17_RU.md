# DockSlot Messenger v1.17 — изменения

- Возвращена кнопка уведомлений в верхнюю навигацию: она возвращается первой слева в навигации, включая размещение перед переключателем темы у оператора.
- Добавлен устойчивый контроль размещения кнопки, чтобы последующая перестройка навигации по роли не удаляла её.
- Сохранена существующая логика счётчика, настроек уведомлений, Realtime и Push.
- Плавающая кнопка чата возвращена на нижнюю правую позицию, ранее занимаемую плавающей кнопкой уведомлений.
- В режиме привязки записи явно включается мини-календарь, скрываются групповые ярлыки и показывается список записей только после выбора даты.
- Для календаря закреплены размеры flex-блока и прокрутка списка, чтобы сетка дней не исчезала при открытии picker.
- Cache-busting обновлён до v1.17.

Новые SQL-миграции и изменения Edge Functions отсутствуют.
