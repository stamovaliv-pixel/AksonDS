# DockSlot Messenger v1.18 — список изменений

- Увеличен внешний символ сообщения, чтобы знак DS свободнее помещался внутри контура.
- Эффект ambient halo заменён на бегущую градиентную полосу по внешнему периметру кнопки в стиле светового sweep Google AI Mode.
- Палитра полосы: голубой, синий, фиолетовый, розовый, красный, жёлтый и бирюзовый; градиент меняется при движении.
- Анимация остаётся привязана к классу `has-unread`: 60-секундный цикл, активная фаза 3 секунды, три оборота.
- Размер/позиция кнопки, бейдж и логика unread не изменялись.
- Обновлены только CSS и cache-busting `chat.css` в соответствующих HTML.
