# DockSlot Messenger v1.8

## Исправления

1. Повторное нажатие на тот же смайл теперь снимает реакцию текущего пользователя. Причина предыдущего поведения — устаревшие строки в локальном массиве реакций, которые сохранялись при merge после успешного удаления в SQL.
2. Клиент применяет boolean-результат `dockslot_chat_toggle_reaction` сразу: `true` добавляет реакцию, `false` удаляет её. Устаревшие данные по сообщениям из текущей загрузки заменяются свежими из Supabase; кэш реакций для более старых сообщений сохраняется.
3. Период ambient-подсветки кнопки изменён на 60 секунд.
4. Пиковая яркость подсветки увеличена на 40%: opacity `0.46` → `0.644`.
5. Полный оборот эффекта сохранён на уровне 1,5 секунды; красно-синий градиент и мягкое свечение под кнопкой сохранены.

## Совместимость

Изменения клиентские. SQL и Edge Functions не изменяются. Требуется основная миграция Messenger v1.2, которая содержит `dockslot_chat_toggle_reaction`.
