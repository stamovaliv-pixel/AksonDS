# DockSlot Messenger v1.9 — список изменений

## 1. Управление сообщениями по наведению

- Кнопка `...` и кнопка реакции скрыты в обычном состоянии.
- Появляются при наведении на карточку сообщения или при фокусе с клавиатуры.
- Меню реакций раскрывается при наведении/фокусе на саму пиктограмму; на сенсорных устройствах контроль доступен без hover.

## 2. Сведения о прочтении

- В меню `...` собственных отправленных сообщений добавлен пункт «Информация о прочтении».
- Отображаются адресаты и время/дата из `dockslot_chat_message_reads.read_at`.
- Для не прочитавших отображается «Не прочитано».

## 3. Адресная пиктограмма по записи слота

- Добавлена SQL RPC-функция `dockslot_chat_booking_links()`.
- Она возвращает только сообщения по записи, доступные текущему сотруднику: собственные сообщения отправителя не показываются ему как адресное уведомление; личные сообщения видит только назначенный получатель; сообщения группового чата — только участник соответствующей группы.
- В карточке дня и в списке записей рабочего стола отображается прозрачная оранжевая пиктограмма при наличии доступного сообщения. В отсутствие связи пиктограмма серая и отключена.
- Переход открывает нужный диалог и конкретное сообщение.
- Карточки доступны для ролей admin, operator и super_admin; поставщики не получают интерфейс и данные этой функции.

## 4. Группа рассылки «Всем»

- Добавлен быстрый выбор «Всем» наряду с «УТЗ» и «РЦ».
- Выбираются все активные пользователи, которым разрешён мессенджер: `admin`, `operator`, `super_admin`, кроме отправителя.
- Существующее серверное ограничение числа получателей (до 200) сохранено.

## 5. Технология доставки сообщений

Механизм отправки и доставки не менялся. Сообщение записывается через существующую серверную RPC-функцию; Realtime используется для оповещения подключённых клиентов об изменениях, а периодическая сверка остаётся резервным механизмом. Для текущего масштаба внутреннего мессенджера оснований менять это на Broadcast в рамках данного патча недостаточно.
