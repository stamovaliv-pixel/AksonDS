# Изменения — ограничение «Возврат» до 17:59 МСК

- Добавлен клиентский контроль срока для создания записи на завтра с типом `return`.
- Добавлен клиентский контроль при добавлении `return` к существующей записи на завтра.
- Время рассчитывается в `Europe/Moscow` независимо от часового пояса устройства.
- Добавлен серверный BEFORE-триггер для INSERT и изменения полей даты/типа поставки в `public.bookings`.
- Серверное ограничение применяется только к авторизованной роли `supplier`.
- Новое правило блокирует действие с 18:00:00 МСК; 17:59 остаётся доступным.
- При сохранении уже установленного типа `return` и редактировании других полей дополнительная блокировка не применяется.
- Прежнее `app_settings.return_deadline_days`, проверки слотов, другие роли и остальные модули не изменялись.
