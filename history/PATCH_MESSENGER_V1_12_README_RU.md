# DockSlot Messenger v1.12 — инструкция по установке

## Назначение

Точечное исправление мессенджера поверх v1.11. Архив содержит только изменённые файлы проекта; полный проект не включён.

## Что исправлено

1. Убраны из пользовательского чата кнопка выбора реакции и отображение установленных реакций. Аналогичное отображение убрано из архива переписок суперадминистратора. Таблицы и SQL-функции реакций не удаляются и не меняются — визуальный функционал можно вернуть позднее.
2. Устранена конкуренция двух механизмов плавной прокрутки. Для сообщений используется один объединяемый запрос на прокрутку с немедленной установкой `scrollTop` после отрисовки.
3. Удалена проверка `bottomScrollRevision`, которая могла отменять финальную прокрутку при параллельной отправке или обновлении.
4. Входящие сообщения активного диалога, собственные оптимистичные сообщения и подтверждённые сервером сообщения инициируют переход к последнему сообщению.
5. Добавлено отслеживание изменения высоты последней карточки через `ResizeObserver`, чтобы оставаться внизу после загрузки изображения/вложения, если пользователь не прокручивал историю вверх.
6. Загрузка сообщений защищена последовательностью запросов и идентификатором активного диалога: устаревший ответ не должен перезаписывать переписку после переключения чата. Оптимистичное сообщение не теряется при параллельном обновлении.
7. Поле ввода пересчитывает высоту от исходного состояния `auto` один раз на кадр. Сам ввод текста остаётся нативным и не задерживается сетевыми запросами или синхронной перерисовкой.
8. Удалено ожидание записи отметки прочтения перед отрисовкой сообщений — сохранение статуса прочтения выполняется в фоне.

## Установка

1. Сделайте резервные копии заменяемых файлов.
2. Распакуйте ZIP поверх корня `AksonDS-main`, сохранив каталоги.
3. Опубликуйте заменённые файлы через RelaxDev.
4. В браузере выполните жёсткое обновление `Ctrl + F5`.

## Что входит

- `js/chat.js`
- `js/chat-management.js`
- `css/chat.css`
- 9 HTML-страниц с обновлёнными cache-busting версиями ресурсов.

## Supabase

SQL-миграция не требуется. Edge Functions и существующие RPC не меняются. Таблицы/функции реакций остаются в базе; отключается только их отображение и клиентское чтение в интерфейсе переписки.

## Проверки

Статически проверены синтаксис JavaScript, разбор HTML-страниц, структура CSS, ссылки на ресурсы, отсутствие старых флагов/кода реакции в клиентском чате и целостность ZIP. Реальный браузерный тест с рабочей Supabase-сессией в этой среде не выполнялся.
