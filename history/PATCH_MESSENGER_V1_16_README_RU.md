# DockSlot Messenger v1.16 — инструкция по установке

Патч добавляет настройки уведомлений о сообщениях, привязку этих уведомлений к существующей системе `app_notifications`, мини-календарь выбора слота и финальную настройку плавающей кнопки.

## Состав

- `js/notifications.js` — пункт личных настроек «DockSlot Чат» и определение активной Push-подписки даже когда окно настроек уведомлений закрыто.
- `css/notifications.css` — положение счётчика уведомлений с небольшим наложением на пиктограмму колокольчика.
- `css/chat.css` — градиент кнопки в цветах знака «DockSlot Команда» и счётчик, выступающий за край кнопки.
- 13 HTML-страниц в `app/` — корректные пути к существующим `chat.js`, `chat.css`, `notifications.js`, `notifications.css` и новые cache-busting версии.
- `supabase/migrations/20261125_dockslot_chat_notification_preferences.sql` — создаёт персональное уведомление для адресата/участника чата, только если в его личных настройках включён «DockSlot Чат».

## Установка

1. Сделайте резервные копии изменяемых файлов.
2. В Supabase Dashboard → SQL Editor выполните `20261125_dockslot_chat_notification_preferences.sql` один раз.
3. Распакуйте ZIP поверх корня `AksonDS-main`, сохранив структуру папок.
4. Опубликуйте изменённые HTML, JS и CSS через RelaxDev.
5. Откройте DockSlot и выполните `Ctrl + F5`.
6. Каждый сотрудник, желающий получать уведомления о сообщениях, открывает колокольчик → настройки → раздел «Сообщения» → включает «DockSlot Чат» → сохраняет настройки.
7. Для всплывающих системных уведомлений на устройстве дополнительно должны быть включены Push в DockSlot и разрешения уведомлений браузера/Windows.

Повторно публиковать Edge Function и повторно запускать предыдущие миграции Messenger не требуется.

## Как доставляются уведомления

- SQL-триггер создаёт строку в существующей `app_notifications` для каждого адресата, который включил `preferences.dockslot_chat.enabled`.
- Личное сообщение отправляется только его адресату; групповое — участникам данного диалога; общий канал — сотрудникам с активным доступом к чату. Отправитель не получает собственное уведомление.
- Открытая вкладка получает событие через Supabase Realtime. Если на этом устройстве есть действующая Push-подписка, `notifications.js` показывает системное уведомление через Service Worker.
- Когда браузер закрыт, доставка зависит от уже настроенного серверного Web Push-обработчика/Database Webhook, который отправляет Push по новым строкам `app_notifications`. Если в webhook настроен allow-list `event_type`, добавьте `dockslot_chat_message`. В этом патче не создаётся новый VAPID-секрет или отдельный push-сервер.
- Нажатие на уведомление открывает соответствующую переписку и конкретное сообщение.

## Примечания

- В окне привязки записи уже используется календарная сетка: по умолчанию выбран сегодняшний день по `Europe/Moscow`; поиск фильтрует записи выбранной даты, стрелки переключают месяцы.
- Существующий формат `notification_preferences.preferences` (JSONB) сохранён; новая колонка не добавляется.
- В CSS счётчик чата выступает за верхний правый край кнопки; счётчик колокольчика слегка заходит на пиктограмму.
- Эффект Ambilight работает только при наличии непрочитанных сообщений: раз в минуту, три оборота за три секунды, затем скрывается.

## Проверки

Выполнены статические проверки JavaScript, ссылок HTML на ресурсы, структуры CSS и целостности ZIP. Реальное применение SQL, отправка Web Push через настройки конкретного Supabase-проекта и браузерный тест на боевой базе в рамках сборки не выполнялись.
