# DockSlot Messenger v1.18 — изменение значка и бегущей подсветки

## Что изменено

1. Внутренний контур сообщения увеличен с 27 до 32 px; знак DS увеличен незначительно до 13.5 px. Размер и форма самой плавающей кнопки не изменялись.
2. Прежнее мягкое свечение заменено на тонкую бегущую градиентную полосу по периметру кнопки с размытым цветным ореолом под ней.
3. Эффект запускается только при наличии непрочитанных сообщений: один раз в 60 секунд, длится 3 секунды и совершает три оборота, затем полностью исчезает.
4. Сохранено поведение при `prefers-reduced-motion`: анимация отключается.

## Что не менялось

- JavaScript и логика мессенджера;
- условия отображения `has-unread`;
- размер и позиция плавающей кнопки;
- счётчик непрочитанных;
- навигация, уведомления и Push;
- SQL, Edge Functions и Supabase;
- остальные стили чата.

## Установка

1. Сохраните резервную копию заменяемых файлов.
2. Распакуйте ZIP поверх корня `AksonDS-main`, сохраняя структуру каталогов.
3. Опубликуйте изменённые файлы через RelaxDev.
4. Выполните Ctrl+F5.

## Состав

- `css/chat.css`
- HTML-страницы из `app/`, где обновлён только cache-busting версии `chat.css`.
- этот README, changelog и SHA256-манифест.

SQL и повторная публикация Edge Functions не нужны.

## Проверки

Проверены ссылки `chat.css` на всех включённых HTML-страницах и целостность ZIP. Реальный браузерный визуальный тест не проводился.
