# DockSlot Messenger v1.19 — инструкция по установке

## Что изменено

- Счётчик непрочитанных сообщений на плавающей кнопке чата вынесен наружу вправо-вверх: внутрь кнопки заходит около 15% бейджа.
- Внутренний знак DS уменьшен до 10 × 10 px, контур облачка и размер кнопки не менялись.
- Счётчик уведомлений позиционируется относительно правого верхнего угла самого глифа колокольчика: на иконку заходит около 15% бейджа. Добавлена тень в стиле счётчиков календаря.
- Стили счётчиков на карточках календаря администратора и страницы дня не менялись. В `admin_calendar.html` и `admin_day.html` обновлены только query-параметры подключаемых CSS для сброса кэша.

## Установка

1. Сделайте резервные копии файлов из ZIP.
2. Распакуйте содержимое поверх корня `AksonDS-main`, сохраняя структуру каталогов.
3. Опубликуйте проект через RelaxDev.
4. Обновите страницу через Ctrl + F5.

SQL-миграции, JavaScript и Edge Functions не изменяются.
