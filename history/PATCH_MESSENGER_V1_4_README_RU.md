# DockSlot Messenger v1.4 — инструкция по установке патча

## Состав

Этот архив содержит только файлы, изменённые относительно DockSlot Messenger v1.3, а также эту инструкцию, список изменений и манифест.

## Установка

1. Сделайте резервную копию текущей версии DockSlot.
2. Распакуйте ZIP с сохранением структуры папок.
3. Скопируйте папки `app`, `css`, `js` в корень проекта DockSlot, согласившись на замену перечисленных файлов.
4. Опубликуйте изменённые файлы проекта обычным способом.
5. Откройте DockSlot с принудительным обновлением страницы (`Ctrl+F5`).

Не распаковывайте архив внутрь дополнительной вложенной папки `AksonDS-main`. В архиве пути уже относительны корню проекта.

## Что входит в патч

- Обновлённый мессенджер: действия сообщения через `...`, пересылка одного сообщения, редактирование своего сообщения в течение разрешённого сервером периода.
- Поиск по сообщениям текущей переписки за период, доступный обычному пользователю.
- Кнопка реакций в виде огонька без фона в правой нижней части сообщения.
- История полного архива суперадминистратора визуально сгруппирована по отправителям, включая дополнительные страницы архива.
- Подпись роли `super_admin` в чате и архиве отображается как «Администратор».
- Уведомления вынесены первым элементом навигации для `admin`, `operator` и `super_admin`; счётчик остаётся привязан к пиктограмме.
- Плавающая кнопка чата занимает прежнее место кнопки уведомлений. Мягкий неоновый ореол находится под ней и делает один плавный оборот раз в 10 минут.
- Иконки вложения, привязки слота и отправки выровнены по центру поля ввода.
- Обновлены cache-busting версии ресурсов в страницах, где эти ресурсы подключаются.

## База данных и Edge Functions

Патч не содержит SQL-миграций и не требует повторной публикации Edge Function `dockslot-chat-admin-history` или `doxi-chat`. Используются действующие таблицы, RPC, Storage и серверная функция архива.

## Проверки

Выполнены статические проверки синтаксиса JavaScript, парности CSS-фигурных скобок, ссылок на локальные ресурсы из HTML и целостности ZIP. Проверка в браузере с реальным Supabase-проектом не выполнялась; после публикации проверьте навигацию уведомлений, меню действий сообщений, поиск и кнопку чата на ролях `admin`, `operator`, `super_admin`. Поставщик не должен получать ни кнопку чата, ни кнопку уведомлений в рамках действующей ролевой модели.
