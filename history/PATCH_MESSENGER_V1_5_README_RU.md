# DockSlot Messenger v1.5 — патч исправлений

## Что исправлено

1. Пиктограмма реакции заменена на компактный SVG-силуэт огня размером 11×11 px. У кнопки прозрачный фон, нет рамки и тени; расположение остаётся в правой нижней части карточки сообщения.
2. При отправке сообщения поле ввода очищается сразу после создания оптимистичного сообщения, не ожидая завершения сетевого запроса. При подтверждённой ошибке черновик возвращается, если пользователь уже не начал набирать новый текст.
3. После добавления сообщения выполняется повторная прокрутка к низу списка после перерисовки и изменения высоты поля ввода.
4. Карточки сообщений используют ширину по содержимому с минимальной шириной 100 px (92 px на узких экранах) и автоматическим расширением до установленной максимальной ширины.
5. Сохранение настроек страницы управления переведено с `UPDATE ... SELECT ... single()` на защищённую RPC `dockslot_chat_update_settings(jsonb)`. Это устраняет зависимость от PostgREST single-object ответа и возвращает понятные серверные ошибки.

## Причина 406 на сохранении

В предыдущем коде обновление завершалось `.select('*').single()`. Если PostgREST не возвращал обновлённую строку (например, из-за RLS/отсутствия строки id=1), он отвечал 406 `Cannot coerce the result to a single JSON object`. Теперь обновление выполняется серверной SECURITY DEFINER функцией с явной проверкой `profiles.role = 'super_admin'` и `profiles.is_blocked = false`. Функция проверяет входные параметры, ограничения и наличие строки id=1, затем возвращает JSONB объект.

## Установка

1. Сделайте резервную копию текущих файлов.
2. Распакуйте ZIP патча поверх корня DockSlot, сохранив структуру папок.
3. Откройте Supabase Dashboard → SQL Editor.
4. Выполните один раз файл `supabase/migrations/20261124_dockslot_chat_settings_admin_rpc_fix.sql`.
5. Обновите страницу управления мессенджером с очисткой кэша браузера (Ctrl+F5).

Повторное применение основной миграции Messenger v1.2 не требуется. Переdeploy Edge Function не требуется. Веб-интерфейс использует существующую Supabase RPC API.

## Тест-план

- Отправить короткий текст клавишей Enter: поле должно очиститься сразу, сообщение должно появиться внизу списка.
- Отправить длинный текст: карточка должна расшириться в пределах допустимого максимума, сохранив перенос длинных слов.
- Открыть огонёк: маленькая прозрачная SVG-пиктограмма должна показываться без подложки.
- На странице управления изменить один параметр и сохранить.
- Повторить сохранение под Admin и Operator: функция должна отказать с 42501.
- Повторить сохранение под Supplier: функция должна отказать с 42501.
