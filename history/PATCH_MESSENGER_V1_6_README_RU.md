# Установка DockSlot Messenger v1.6

1. Сделайте копии файлов из архива, которые уже существуют в вашем проекте.
2. Распакуйте содержимое ZIP поверх корня `AksonDS-main`, сохранив каталоги `js`, `css`, `app`.
3. Опубликуйте обновлённые файлы через RelaxDev.
4. В браузере выполните Ctrl+F5.

Патч содержит только изменённые клиентские файлы. SQL Editor, повторная публикация Edge Function и изменения Supabase не требуются.

## Проверка после публикации

- Откройте выбор реакции: панель должна быть компактной, в один ряд, без перекрытия большей части карточки.
- Убедитесь, что «Трогает» отображается как 🥺.
- Проверьте ширину: короткое сообщение должно занимать ширину по содержимому с компактным минимумом; длинный текст должен расширять карточку и переноситься в пределах окна чата.
- Отправьте сообщение Enter и кнопкой отправки: поле ввода должно очиститься, а последнее сообщение оказаться внизу.
- Проверьте, что устаревшее фоновое обновление не возвращает прокрутку вверх.
- Свечение под кнопкой должно быть красно-синим, мягким, ярче предыдущего и включаться один раз примерно в 10 минут.

Примечание: системный вид цветных emoji зависит от версии emoji-шрифта в Windows. В патче задан единый системный emoji-font stack и мягкая тень; отдельные emoji-font файлы в архив не включаются.
