# DockSlot Messenger v1.7 — установка точечного патча

Патч v1.7 подготовлен поверх клиентской сборки Messenger v1.6. Архив содержит только два клиентских ресурса и HTML-страницы, в которых обновлена версия подключения ресурсов.

## Что изменено

1. Кнопка `...` в карточке сообщения сделана компактнее.
2. Выпадающее меню оформлено в стиле DockSlot: небольшая панель, компактные строки, нейтральные пиктограммы, мягкая тень и поддержка светлой/тёмной темы.
3. Для собственного сообщения добавлен явный пункт «Редактировать».
4. Если сообщение отправлено менее 10 минут назад, пункт активен. После истечения срока он остаётся видимым, но неактивным и показывает подсказку о лимите времени.
5. Для чужих сообщений пункт «Редактировать» не выводится; действие «Переслать» остаётся доступным в рамках существующих прав.
6. Сравнение ID автора и текущего пользователя нормализовано через `String`, чтобы не скрывать действие из-за различия типов значений.
7. Клиентская проверка времени учитывает небольшой отрицательный допуск для рассинхронизации часов браузера. Серверная SQL-функция остаётся окончательным источником проверки.

## Установка

1. Сделайте резервные копии заменяемых файлов.
2. Распакуйте ZIP в корень `AksonDS-main`, сохранив структуру папок.
3. Опубликуйте заменённые файлы через RelaxDev.
4. Обновите DockSlot в браузере через `Ctrl+F5`.

## Важное о правиле 10 минут

В патче не меняется база данных. Используется существующая RPC-функция `dockslot_chat_edit_message`, добавленная в миграции Messenger v1.2. Она проверяет, что сообщение принадлежит текущему пользователю, что пользователь имеет доступ к диалогу и что с момента `created_at` прошло не более 10 минут. Клиентская кнопка не заменяет серверную проверку.

Повторно выполнять SQL-миграции или публиковать Edge Function для этого патча не требуется, при условии что миграция Messenger v1.2 уже применена в Supabase.
