# DockSlot Messenger v1.8 — точечный патч

Патч v1.8 подготовлен на базе клиентской сборки Messenger v1.7. В ZIP включены только изменяемые файлы DockSlot (2 ресурса и 9 HTML-страниц для обновления cache-busting версии), а также документация патча.

## Что исправлено

### 1. Повторное нажатие снимает свою реакцию

SQL-функция `public.dockslot_chat_toggle_reaction(uuid, text)`, добавленная основной миграцией Messenger v1.2, уже работает как переключатель: удаляет существующую реакцию текущего пользователя и возвращает `false`; если реакции не было — добавляет её и возвращает `true`.

Проблема находилась в клиентской синхронизации. После обновления сообщений код объединял старый и новый массивы реакций, из-за чего удалённая реакция оставалась в памяти и продолжала отображаться. В v1.8 для всех сообщений, повторно загруженных текущим запросом, старые реакции заменяются свежими данными. Для более старых сообщений, не входивших в запрос, их локальные реакции сохраняются.

При выборе реакции клиент также обрабатывает boolean-результат RPC и сразу обновляет интерфейс: `true` — реакция добавлена, `false` — реакция снята. Это не требует ожидания Realtime или полной перезагрузки чата.

### 2. Подсветка плавающей кнопки чата

- Период повторения эффекта: 60 секунд (1 раз в минуту).
- Продолжительность полного оборота: 1,5 секунды.
- Пиковая opacity увеличена с 0,46 до 0,644 (+40%).
- Существующий красно-синий мягкий градиент и расположение свечения под кнопкой сохранены.

## Файлы проекта в архиве

- `js/chat.js`
- `css/chat.css`
- 9 HTML-страниц `app/*.html`, в которых обновлён параметр версии подключаемых ресурсов с `v1-7` на `v1-8`.

SQL-миграция и Edge Function не меняются. Повторно выполнять SQL или публиковать Edge Function не требуется, если базовая миграция Messenger v1.2 уже установлена.

## Установка

1. Сделайте резервные копии заменяемых файлов.
2. Распакуйте архив в корень `AksonDS-main`, сохранив структуру папок.
3. Опубликуйте заменённые файлы через RelaxDev.
4. В браузере выполните жёсткое обновление `Ctrl+F5`.
