# DockSlot Messenger v1.9 — инструкция по установке

Патч v1.9 — delta-архив: содержит только файлы, изменённые относительно предыдущей сборки Messenger v1.8. Полный проект, старые миграции и Edge Functions в архив не включены.

## Состав

- `js/chat.js` — скрытие действий до наведения, информация о прочтении, навигация к сообщению по записи, группа рассылки «Всем».
- `js/admin_day.js` — адресный индикатор на карточках записей дня для ролей admin, operator и super_admin.
- `js/admin_overview.js` — адресный индикатор в списке записей на рабочем столе администратора.
- `css/chat.css` — hover-поведение кнопки действий и реакции, стили адресного индикатора и сведений о прочтении.
- `app/admin_day.html`, `app/admin_overview.html` — обновлены версии подключаемых ресурсов для сброса кэша.
- `supabase/migrations/20261125_dockslot_chat_booking_links.sql` — безопасная функция получения адресных сообщений по слотам для текущего пользователя.

## Порядок установки

1. Сделайте резервные копии файлов, которые будут заменены.
2. Распакуйте архив, сохраняя структуру `AksonDS-main/...`, поверх корня проекта.
3. В Supabase Dashboard откройте **SQL Editor** и выполните `supabase/migrations/20261125_dockslot_chat_booking_links.sql`.
4. После успешного выполнения опубликуйте обновлённый фронтенд через используемый вами процесс RelaxDev.
5. В браузере обновите страницу через `Ctrl+F5`.

SQL-миграция идемпотентна: используется `CREATE OR REPLACE FUNCTION`, права функции задаются явно. Выполнять её нужно после основной миграции Messenger v1.2, которая создаёт таблицы и вспомогательные функции чата.

Повторно разворачивать `dockslot-chat-admin-history` и повторять основную миграцию Messenger v1.2 не требуется.

## Поведение

- Кнопки `...` и реакции скрыты до наведения указателя на сообщение. На сенсорных экранах они остаются видимыми, поскольку там нет hover.
- Меню `...` содержит сведения о прочтении для собственных отправленных сообщений, а также пересылку и редактирование в пределах действующего десятиминутного ограничения.
- В сведениях о прочтении показываются адресаты и дата/время чтения; для ещё не прочитавших отображается «Не прочитано».
- На карточке слота оранжевая и активная пиктограмма появляется только если текущему пользователю доступно адресное сообщение по этой записи. В остальных случаях она серая и некликабельная.
- Нажатие на активную пиктограмму открывает соответствующий чат и прокручивает его к связанному сообщению.
- Для поставщиков функция чата и RPC-выдача связанных сообщений недоступны.
- Группа «Всем» включает пользователей с разрешёнными настройками мессенджера ролей `admin`, `operator` и `super_admin`, кроме самого отправителя; серверная функция создания группы повторно проверяет права каждого выбранного участника.

## Проверки

В архиве выполнены статические проверки синтаксиса изменённых JavaScript-файлов, баланса CSS-фигурных скобок, наличия обновлённых cache-busting версий в двух HTML-страницах и целостности ZIP. SQL не выполнялся на вашей рабочей базе; после применения миграции проверьте доступность RPC и работу пиктограмм под тестовыми аккаунтами admin, operator и super_admin.
