# DockSlot — безопасное отключение «Доски смены»

## Что отключено

- Убран пункт «Доска смены» из навигации `super_admin`.
- Удалены клиентские файлы отдельного функционала: `js/shift-board.js` и `css/shift-board.css`.
- `app/shift_board.html` оставлен как минимальная redirect-страница: старые закладки автоматически переводят пользователя на штатный `admin_calendar.html`.
- Удалено название этой страницы из контекста разделов Докси.
- Обновлён cache-buster общего `admin-navigation.js`, чтобы браузер не продолжал использовать прежнее меню.

## Что не затрагивалось

- `app/admin_day.html` и `js/admin_day.js` — штатная страница дня администратора.
- `app/day.html` и `js/day.js` — штатная страница дня поставщика.
- Календарь, рабочий стол администратора, аналитика, настройки, уведомления и Докси.
- Таблица `bookings`, её записи, поля `arrival_time`, `departure_time`, `gate_number`, RLS, триггеры и SQL-функции.
- Сама таблица `public.shift_board_settings` пока сохранена до проверки её зависимостей и содержимого. Строка этой таблицы в матрице доступа Докси удаляется отдельной миграцией `20261117_doxi_remove_shift_board_settings.sql`.
- Историческая миграция `20261116_doxi_table_access_matrix.sql` остаётся неизменной; новая миграция компенсирует её старую запись.
- Edge Function очищается отдельным обновлением DOXI 3.4.9; Supabase secrets, Ollama и Proxy не меняются.

## Почему данные не теряются

Доска смены читала активные записи из `bookings` и могла изменять в них время прибытия, убытия и номер ворот. Те же поля уже присутствуют на штатной странице `admin_day.html`, где продолжают работать их просмотр и редактирование. Удалён только дублирующий экран и его клиентский код; сами столбцы и записи не менялись.

## Дополнительное сохранённое изменение Докси

В `js/ai-ds.js` сохранено исправление стартовых вопросов: нажатие на стартовый вопрос сразу отправляет его в чат через общий обработчик `send()`. Добавлена защита от быстрой повторной отправки двойным кликом.

## Установка полного архива

1. Сохраните текущий репозиторий как резервную копию.
2. Замените проект содержимым полного архива `AksonDS-main`.
3. Опубликуйте изменения обычным способом.
4. После публикации обновите страницу DockSlot через `Ctrl+F5`.

## Установка только патча

1. Замените файлы из патча, сохраняя пути относительно `AksonDS-main/`.
2. Удалите два файла из списка `FILES_TO_DELETE.txt`.
3. Опубликуйте изменения и выполните `Ctrl+F5`.

Для этого первого отключения SQL и Edge Function менять не требовалось. Для последующей очистки матрицы доступа используйте отдельную инструкцию `README_DOXI_3_4_9_SHIFT_BOARD_CLEANUP_RU.md`.
