Ключи системных уведомлений ДокСлота

Генератор создаёт VAPID-ключи для Web Push и отдельный секрет для связи Supabase Database Webhook с Edge Function. Всё генерируется локально в этом браузере.

Важно: приватный VAPID-ключ и секрет webhook нельзя добавлять в GitHub, HTML-код сайта или отправлять в чат. Они предназначены только для Secrets в Supabase. Публичный VAPID-ключ, наоборот, будет добавлен в js/push-config.js.
